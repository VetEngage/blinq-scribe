# Docs

Product documents for Blinq Scribe. Committed to the repo so judges and teammates can read them.

| File | What it is |
| --- | --- |
| `Blinq Scribe PRD and Product Spec.md` | The product: problem, users, goals, requirements, architecture, API, AI rules, PIMS connection, release plan |
| `Blinq Scribe iPhone App PRD.md` | The glasses companion app brief, written for Muse Code to build from |

To hand the iPhone app to Muse Code, run from the repo root:

```bash
muse exec --prompt-file "_Docs/Blinq Scribe iPhone App PRD.md"
```
